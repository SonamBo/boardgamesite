How to play Picture Logic: solving nonograms

Picture Logic puzzles, also called nonograms, hide a picture behind a grid of number clues. Every one can be solved by logic alone. Here’s how.

The rules

Each row and column has a clue: a list of numbers. Each number is a run of filled squares in that line, in order, with at least one empty square between runs. A row with the clue 2 3 has a run of two, a gap, then a run of three. A clue of 0 means the whole line is empty. Fill squares so every clue is matched, and the picture appears.

Technique 1: the overlap

This is the most useful trick. Take a row of 10 with a clue of 7. Push the run as far left as it can go: it covers squares 1 to 7. Push it right: squares 4 to 10. Squares 4 to 7 are filled either way, so fill them now. The same works for several numbers: imagine every run pushed left, then every run pushed right, and fill the squares where the same run overlaps itself.

Technique 2: lines that add up

Add the numbers in a clue, plus one gap between each. If the total equals the length of the line, the whole line is fixed. In a 10-square row, 3 2 3 adds up to 3 + 2 + 3 + 2 gaps = 10, so there’s only one way to fill it.

Technique 3: edges

A filled square touching the edge of the grid must be the start of the first (or last) run. If the clue starts with 4, the first four squares are filled and the fifth is empty.

Technique 4: cross out

When a line’s clue is complete, every other square in it is empty. Cross them out. Crosses are just notes, but they make the next deduction much easier to see.

Technique 5: back and forth

Every square you decide in a row is new information for its column, and the other way round. Work through the rows, then the columns, then the rows again. Each pass reveals a little more until the picture is complete.

A tip for big grids

On 15×15 puzzles, start with the biggest numbers. They give the most overlap. The thicker lines every five squares help you count without losing your place.
