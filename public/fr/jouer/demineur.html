Comment jouer

Dévoilez toutes les cases sans mine. Chaque chiffre indique combien de mines touchent cette case, diagonales comprises. Posez un drapeau sur les cases dont vous êtes sûr qu’elles cachent une mine.

Comment jouer au démineur

Le démineur est un jeu de logique sur une grille de cases cachées. Certaines dissimulent des mines. Pour gagner, dévoilez toutes les cases sûres sans tomber sur une mine.

  1. Touchez une case pour creuser. Le premier coup est toujours sûr et ouvre une zone du terrain.
  2. Lisez les chiffres. Un chiffre indique combien de mines se trouvent dans les huit cases qui l’entourent : au-dessus, en dessous, sur les côtés et en diagonale. Une case vide n’a aucune mine autour d’elle.
  3. Marquez les mines. Quand vous êtes sûr qu’une case cache une mine, faites un appui long, un clic droit, ou passez en mode Drapeau et touchez-la.
  4. Dégagez autour d’un chiffre. Quand toutes les mines d’un chiffre sont marquées, touchez-le pour ouvrir d’un coup toutes les autres cases qui l’entourent.
  5. Vous gagnez en dévoilant toutes les cases sans mine. Creusez une mine, et la partie est perdue.

Il existe trois tailles de terrain. Facile : 9×9 avec 10 mines ; Moyen : 16×16 avec 40 ; Difficile : 30×16 avec 99. Sur téléphone, le grand terrain pivote pour que chaque case soit assez grande.

Astuces pour déminer

  • Commencez par les 1. Un 1 qui n’a qu’une seule case cachée à côté signifie que cette case est une mine.
  • Comptez les drapeaux déjà posés. Si un 2 a déjà deux drapeaux autour de lui, toutes les autres cases voisines sont sûres.
  • Comparez les chiffres voisins. Deux chiffres côte à côte partagent la plupart de leurs voisines. Les comparer révèle souvent les cases sûres.
  • Ne devinez qu’en dernier recours. Parfois, les chiffres ne peuvent vraiment pas trancher, souvent sur les dernières cases. C’est alors pile ou face.

Questions fréquentes sur le démineur

Est-ce le démineur classique ?

Oui. Les règles sont celles du démineur classique : dévoilez les cases sûres, servez-vous des chiffres pour trouver les mines et marquez-les d’un drapeau.

Le premier coup est-il toujours sûr ?

Oui. Les mines sont placées après votre premier coup, jamais sur cette case ni sur ses voisines : vous commencez toujours avec une zone ouverte.

Comment poser un drapeau sur téléphone ?

Gardez le doigt sur la case environ une demi-seconde, ou passez la commande Creuser / Drapeau sur Drapeau et touchez. Revenez sur Creuser pour continuer.

Chaque partie peut-elle se résoudre sans deviner ?

Pas toujours. Comme dans le jeu classique, les mines sont placées au hasard : il arrive que les chiffres ne permettent pas de savoir quelle case est sûre.

Le démineur est-il gratuit ?

Oui. Jouez autant de parties que vous voulez dans votre navigateur, sur n’importe quel appareil, sans téléchargement ni compte.
