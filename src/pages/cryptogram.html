How to play Cryptogram

A cryptogram is a saying written in a simple code. Every letter has been swapped for a different one, and the same letter is always swapped the same way. If A has become Q once, every Q in the puzzle is an A.

  1. Pick a square. The small letter is the code. Every square with the same code letter is highlighted.
  2. Type the letter you think it really is. It fills in everywhere that code letter appears.
  3. Change your mind any time. Type a different letter, or clear it.
  4. Reveal the whole saying to crack the code.

No letter ever stands for itself. If you use the same answer for two different code letters, both turn red. Easy puzzles start with the three most common letters revealed, Medium with one, and Hard with none. Hint reveals one letter.

Quick tips for cracking codes

  • Start with one-letter words. They’re almost always A or I.
  • Look for common short words. Three-letter words are often THE or AND. Two-letter words like OF, TO, IS, IT and IN are common too.
  • Count letters. The most common code letter is often E, T or A.
  • Watch for apostrophes. A letter after an apostrophe is usually S or T.
  • Look for patterns. A word like XYZZY with a double letter narrows things down fast.

Cryptogram FAQ

Is Cryptogram free?

Yes. Play as many puzzles as you like, free in your browser on any device. No download and no account needed.

Can a letter stand for itself?

No. Every letter is swapped for a different one.

Where do the sayings come from?

They’re well-known proverbs and sayings, and a few lines from classic writers such as Shakespeare and Benjamin Franklin.

What does a red letter mean?

You’ve used the same answer for two different code letters. One of them must be wrong.

Will my puzzle be saved?

Yes. Your guesses and time are saved in your browser until you finish.
